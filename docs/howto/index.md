# How-To Guides

Task-oriented recipes for common Acropole workflows. Each guide assumes you already have
`acropole` installed (see the [Getting Started](../tutorials/getting-started.md) tutorial).

## Available Guides

- **[Analyse a complete flight](analyse-a-flight.md)** — load a real flight, plot its
  trajectory, estimate fuel flow and compare it to the measured values.
- **[Map your own column names](columns-mapping.md)** — point each feature at the column
  it lives in, without renaming your frame.
- **[Estimate multi-aircraft frames](multi-aircraft.md)** — score a frame that mixes
  several typecodes in one call.
- **[Provide derivatives or `second`](derivatives.md)** — control how accelerations are
  computed for the model.
